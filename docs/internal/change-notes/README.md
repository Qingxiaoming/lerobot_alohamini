# Change Notes

Use this directory for dated repair, enhancement, migration, or validation records that do not belong
in public user documentation.

Name each record `YYYY-MM-DD-<scope>-<slug>.md`. Every record should state:

- the affected scope and files;
- the observed problem or requested enhancement;
- what changed;
- how it was verified;
- remaining limitations or follow-up work.

Do not place new fix logs, enhancement logs, session notes, or generated reports in the repository root.
Update this index whenever a new record is added.
