# Policy Package README Files

These files provide the short paper, citation, license, or package summaries displayed beside policy
source code. They are deliberately separate from the longer, user-facing policy pages under
[`docs/source/`](../../source/).

Where a source-local README exists, `src/lerobot/policies/*/README.md` is a symlink into this
directory. When adding or renaming a policy README, update the source symlink and the policy-authoring
instructions together.
